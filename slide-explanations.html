Slide 01

Sensitivity & specificity

Sensitivity and specificity help us evaluate decisions whenever a target can be present or absent. A target might be a cat in a photo, smoke near an alarm, or a faint sound in a listening task. First decide what counts as the target. Then compare the decision with what actually happened.

Sensitivity asks how often we notice the target when it is there. Specificity asks how often we correctly say the target is absent when it is absent. We need both: a system that always says “yes” catches every target but also produces a false alarm on every target-absent case.

This deck begins with a simple machine learning example and gradually connects the same ideas to sensory neuroscience. Every numerical example is invented for teaching. Use Explain on any slide to read its walkthrough. The original deck remains available through the Original version link.

Slide 02

A model looks for cats

Imagine a model that checks photos for cats. This is a binary classification task because it gives one of two answers: cat present or cat absent. The actual photo content is the reference label against which we evaluate its answer.

Our test set contains 20 cat photos and 80 photos without cats. Calling cat the “positive” class is simply a naming convention. A positive result does not mean good news, and a negative result does not mean a mistake.

For a real model, test on photos that were not used to train it or choose its decision threshold. Here, the small test set is a teaching example. It lets us count every decision and see exactly which cases go into each metric.

Slide 03

Four possible answers

There are two facts to keep separate: what is actually in the photo, and what the model says. Combining two actual situations with two possible answers creates four outcomes.

When a cat is present, the model can detect it correctly or miss it. These are a true positive and a false negative. When a cat is absent, the model can raise a false alarm or correctly reject the photo as a cat photo. These are a false positive and a true negative.

The everyday names can be easier to remember than the abbreviations. A miss means a cat was there but the model said no. A false alarm means the model said cat when there was no cat. Both are errors, but they occur in different actual groups.

Slide 04

The results in 100 photos

This table is a confusion matrix. The columns represent the actual photo content. The rows represent the model’s answers. The model correctly detects 18 cats and misses two. It raises eight false alarms on photos without cats and correctly rejects the remaining 72.

Check the totals before computing a percentage. The actual-cat column contains 18 + 2 = 20 photos. The no-cat column contains 8 + 72 = 80 photos. Together they make 100. The model gives 26 positive answers and 74 negative answers.

We will use this same table for sensitivity and specificity. The numerator and denominator change according to the question. Keeping the four counts visible helps avoid confusing actual positives with positive predictions.

Slide 05

Sensitivity: finding the cats

Start by setting aside every photo without a cat. For sensitivity, we only care about the 20 photos that really contain cats. Of those, the model detects 18. Therefore sensitivity = 18 / 20 = 90%.

The two missed cats account for the remaining 10%. This is the false negative rate: two misses divided by 20 actual positives. Sensitivity and the false negative rate add up to one because they divide the same group into detected and missed cases.

Sensitivity tells us how thoroughly the model finds cats. It does not tell us whether every “cat” answer is correct, because we have ignored the photos without cats. That is why we must also examine false alarms and specificity.

Open slide 5 ↗

Slide 06

Specificity: rejecting photos without cats

For specificity, set aside every photo that contains a cat. Focus on the 80 photos without cats. The model correctly says “no cat” on 72, so specificity = 72 / 80 = 90%.

The eight false alarms make up the remaining 10% of actual negatives. Therefore false positive rate = 8 / 80 = 10%, which also equals 1 − specificity. Here “rate” means a fraction of negative cases, not a number of alarms per hour.

Notice that sensitivity and specificity are both 90%, even though they use different counts. This is possible because each percentage describes a different actual group. Specificity does not use the 18 correctly detected cats or the two missed cats.

Open slide 6 ↗

Slide 07

The difference is the starting group

The easiest way to distinguish the metrics is to ask which group you start with. Sensitivity starts with actual positives, then asks how many were detected. Specificity starts with actual negatives, then asks how many were correctly rejected.

These percentages are not opposite pieces of one whole. Their denominators are different. Sensitivity plus false negative rate equals 100%. Specificity plus false positive rate equals 100%. Sensitivity plus specificity has no requirement to equal 100%.

A system can have high values on both if it distinguishes the classes well. If it always answers yes, sensitivity becomes 100% and specificity becomes 0%, assuming both actual groups are present. If it always answers no, those values reverse. Neither extreme is a useful general detector.

Slide 08

A stricter or looser decision

A model often produces a score before it produces a yes/no answer. The threshold says how high that score must be for a positive answer. This slide uses a new simulated score model so that you can change that threshold smoothly.

The teal curve describes scores for actual cat photos, and the orange curve describes scores for photos without cats. The vertical line is the threshold. Scores on its right produce “cat” answers. Move it left to make the rule looser: more cats are detected, but more non-cat photos trigger false alarms. Move it right to make the rule stricter.

Both curves stay fixed while the threshold moves. You are changing the decision rule rather than improving the model. Each curve has an area of one, so curve heights do not indicate prevalence. The displayed counts are rounded expected counts for 20 cat photos and 80 photos without cats, not the exact earlier table.

Slide 09

Choosing between two settings

This table makes the trade-off concrete. The looser setting finds 18 of 20 cats but falsely flags 16 of 80 non-cat photos. Its sensitivity is 90% and specificity is 64 / 80 = 80%. The stricter setting finds 14 cats and falsely flags four non-cat photos. Its sensitivity is 70% and specificity is 76 / 80 = 95%.

The stricter setting reduces false alarms from 16 to four, at the cost of increasing misses from two to six. Whether that is worthwhile depends on how the output will be used.

If a person will review a short list and wants to avoid overlooking cats, a looser setting might help. If the model will automatically place photos into a cat album and mistakes are especially annoying, a stricter setting might fit better. The task determines the acceptable trade-off.

Slide 10

The same idea in a smoke alarm

A smoke alarm is a familiar way to remember the distinction. If the target smoke condition is present and the alarm sounds, that is a correct detection. If that condition is present and the alarm stays quiet, that is a miss. If the target condition is absent and the alarm sounds, that is a false alarm.

Sensitivity measures the proportion of target-present tests that produce an alarm. Specificity measures the proportion of target-absent tests that remain quiet. A detector that sounds continuously would have perfect sensitivity and zero specificity, so sounding often is not enough to demonstrate a useful alarm.

For a real evaluation, precisely define the target condition and the test procedure. For example, the target could be a specified smoke exposure rather than the broader condition “there is a dangerous fire.” The same alarm might count differently depending on which condition the evaluation actually targets. This slide makes no claim about a real product.

Slide 11

Sensitivity, precision and accuracy

We return to the original table: 18 correct detections, two misses, eight false alarms, and 72 correct rejections. Sensitivity is 18 / 20 = 90%, because the denominator contains all actual cats.

The model gives 26 “cat” answers: 18 true positives plus eight false positives. Precision asks how many of those positive answers are right. It is 18 / 26 ≈ 69.2%. This is also called positive predictive value. A model can catch most actual cats while producing a noticeable fraction of incorrect cat labels.

Accuracy uses all 100 photos. There are 18 + 72 = 90 correct answers, so accuracy is 90%. Its numerical equality with sensitivity here is a feature of this example, not a general identity. Each metric describes a different group, so choose the one that matches the question.

Slide 12

Prevalence: how common is the target?

Prevalence means the proportion of cases where the target is actually present. If 100 of 1,000 photos contain cats, cat prevalence is 10%. If only ten contain cats, prevalence is 1%. It depends on the actual labels, not the model’s guesses.

At 10% prevalence, 90% sensitivity gives 90 correct cat detections. The 900 non-cat photos produce 90 false alarms at a 10% false positive rate. Precision is 90 / 180 = 50%. At 1% prevalence, the same sensitivity detects nine cats, while 990 non-cat photos produce 99 false alarms. Precision becomes 9 / 108 ≈ 8.3%.

Even a small fraction of a very large negative group can outnumber the true detections from a small positive group. This comparison assumes sensitivity and specificity stay fixed. In practice, a different population may also contain harder photos or different noise, changing those conditional rates.

Slide 13

Listening for a faint beep

Now replace the photo model with a person. In a sensory experiment, the experimenter sometimes plays a faint beep in background noise and sometimes presents background noise alone. After each trial, the participant reports whether they heard the beep. The experimenter knows which trials contained the target.

The participant says yes on 40 of 50 beep trials. These are hits, and the remaining ten are misses. They also say yes on ten of 50 no-beep trials. These are false alarms, while the other 40 are correct rejections. Classification sensitivity, or hit rate, is 80%. Specificity, or correct rejection rate, is also 80%.

The mathematical structure is identical to cat detection. The neuroscience question adds another issue: does a change in answers reflect better sensory evidence, or a different willingness to say yes? We need both target-present and target-absent trials to examine that distinction.

Open slide 13 ↗

Slide 14

Saying yes more often

Imagine the participant ignores the sound and answers yes on every trial. Every actual beep receives a yes, so hit rate, or classification sensitivity, reaches 100%. But every no-beep trial also receives a yes. There are no correct rejections, so specificity is 0%.

This response strategy gives no evidence that the participant can distinguish beep trials from no-beep trials. It shows why a high hit rate alone is insufficient to demonstrate good sensory discrimination.

Less extreme shifts can happen if instructions encourage guessing yes whenever uncertain or encourage yes only when completely confident. Both policies can change hit and false alarm probabilities without changing the quality of the sensory information. Signal detection theory models these as changes in the decision criterion.

Slide 15

Evidence and the decision rule

The curves describe an observer’s internal evidence on no-beep trials and beep trials. Even without a beep, background noise can generate some evidence of a sound. The observer says yes whenever that evidence exceeds a decision threshold.

Keep evidence separation fixed and move the willingness slider toward “more willing.” The observer reports more beeps, increasing hit rate, but also raises more false alarms. Then return willingness to the middle and increase evidence separation. The observer can now distinguish the two conditions more reliably, increasing both sensitivity and specificity in this model.

In signal detection theory, evidence separation is called d′. Under this equal-variance Gaussian model, d′ = z(hit rate) − z(false alarm probability). It is a separation measure, not a percentage. Neuroscience papers sometimes call d′ “sensitivity,” so check whether the author means d′ or the hit rate. The criterion interpretation depends on the model assumptions.

Slide 16

Reading information from brain activity

A neural decoder is a model that uses brain measurements to predict a known label. For example, a participant views cat and non-cat photos while a researcher records neural activity. The decoder tries to identify which kind of photo the participant saw.

The actual stimulus label defines the target. Sensitivity measures how many cat-viewing trials the decoder identifies as cat trials. Specificity measures how many no-cat trials it correctly rejects. We evaluate predictions on held-out data chosen to match the intended generalization, such as new trials or new participants.

This connects the first and last parts of the deck: the data source changes, but the confusion matrix logic remains. Also be careful with informal language. Describing a neuron as “specific” or selective for a stimulus does not automatically define TN / (TN + FP). That metric needs a target label and a binary decision rule.

Slide 17

A quick check

The target is a red ball. There are ten actual red balls, and the person finds eight. So TP = 8, FN = 2, and sensitivity = 8 / (8 + 2) = 80%.

There are 30 actual non-red balls. The person incorrectly calls three of them red, giving FP = 3. The remaining 27 are correctly rejected, giving TN = 27. Specificity = 27 / (27 + 3) = 90%.

The 72.7% option is precision: the person names eleven balls as red, and eight of those names are correct, giving 8 / 11 ≈ 72.7%. The final option reverses sensitivity and specificity. Before calculating, ask whether you are looking at actual targets, actual non-targets, or positive answers.

Slide 18

The two questions to remember

The central distinction is the actual condition. If the target is present, sensitivity asks whether you find it. If the target is absent, specificity asks whether you correctly reject it. This applies to a model searching for cats, an alarm detecting a defined smoke condition, or a person listening for a faint beep.

Both measures use actual labels. Precision instead starts with positive answers, while prevalence describes how common the target is in the data. When you read a percentage, identify its denominator before interpreting it. Sensitivity and specificity are not complements and do not have to add to 100%.

For real results, specify the target, decision rule, evaluation unit, and reference labels. Report counts and appropriate uncertainty. The classification definitions are described in the linked scikit-learn documentation. The linked Stanislaw and Todorov paper explains signal detection measures, including d′.
