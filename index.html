The decision and the actual situation

Four possible outcomes

Sensitivity versus specificity

The difference is the starting group

Sensitivity

Start with everything that contains the target.

How much did we detect?

18 / 20 = 90%

Its error is a miss.

Specificity

Start with everything that lacks the target.

How much did we correctly reject?

72 / 80 = 90%

Its error is a false alarm.

They can both be high. They do not have to add up to 100%.

A high hit rate can have several causes

What if you always answer “yes”?

100%

Sensitivity

You say “yes” on every trial that contains a beep.

0%

Specificity

You also say “yes” on every trial without a beep.

To evaluate perception, we need to measure false alarms as well as hits.

Expectations or instructions can change how willing someone is to report a faint sound.

A bridge back to machine learning

A model can read a label from brain activity

The question

A person views a photo.

A model uses measured brain activity to predict:
“Cat present” or “cat absent.”

This is a neural decoding task.

The same evaluation

Sensitivity: how many actual cat-viewing trials does the model detect?

Specificity: how many actual no-cat trials does it correctly reject?

The input has changed from photos to brain activity. The definitions stay the same.

Conceptual example. A good decoder alone does not establish a unique or causal role for the recorded activity.

Try it yourself

A person finds 8 of 10 hidden red balls

They also point to 3 of 30 non-red balls and call them red.

What are sensitivity
and specificity?

A useful first step

Write down the actual groups:

10 red balls
30 non-red balls

Show the counts

8 found, 2 missed.
3 false alarms, 27 correctly rejected.

Answer: sensitivity = 8 / 10 = 80%. Specificity = 27 / 30 = 90%.

The two questions to remember

Present: did we find it? Absent: did we reject it?

Sensitivity

When the target is there,
how often do we detect it?

TP / (TP + FN)

Higher sensitivity means fewer misses.

Specificity

When the target is absent,
how often do we reject it?

TN / (TN + FP)
