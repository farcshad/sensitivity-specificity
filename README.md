# Sensitivity & specificity

[Open the slides](https://farcshad.github.io/sensitivity-specificity/) · [Reading guide](https://farcshad.github.io/sensitivity-specificity/slide-explanations.html)

18 interactive slides using general examples: cat photos, smoke alarms, finding red balls, and hearing a faint beep. Begins with machine learning and connects the same definitions to sensory neuroscience. Explanations are included for every slide. All numbers are teaching examples.

## Original version

[Original slides](https://farcshad.github.io/sensitivity-specificity/original.html) · [Original explanations](https://farcshad.github.io/sensitivity-specificity/original-explanations.html)

## Controls

Use left/right arrow keys to navigate. Click Explain or press E for a slide walkthrough. F toggles fullscreen. The guide has its own print button.

## Hosting

GitHub Pages serves the root of the main branch. No build step or dependencies are needed. Keep both the new and original HTML files together.
