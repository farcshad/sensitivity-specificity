# Sensitivity and specificity

An interactive 18-slide teaching deck, starting with machine learning and moving into EEG and sensory neuroscience. Includes explanations for every slide, a printable reading guide, and interactive threshold demonstrations.

## Publish with GitHub Pages

1. Create a GitHub repository. A public repository works with GitHub Free.
2. Upload `index.html`, `slide-explanations.html`, and `.nojekyll` to the root of the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.
6. Once deployment finishes, open the website link displayed on the Pages settings screen.

Keep both HTML files in the same folder. No build step or dependencies are required. The website is intended for public access.

## Controls

- Left/right arrows or Space: navigate slides
- Explain button or E: detailed slide explanation
- N: presenter notes
- F: fullscreen
- Print: export slides through the browser

The reading guide includes its own print button. All teaching examples are illustrative unless explicitly attributed to a published study. References are included in the deck and guide.
